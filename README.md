### AISPY v0.0.1

## Description
Module of tools to simplify the creation ais++ input files, as well as the analysis of output files.

Version 0.0.1 enables simulations of multi-loop Mach-Zehnder sequences on the Sr87 ultranarrow sequence. Full description of the project to follow. It is for use with ais++ v0.0.1.

## Installation
Clone this repository, then go in the top directory of the project and run
```
pip install .
```
